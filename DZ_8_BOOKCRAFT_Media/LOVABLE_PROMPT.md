# Промт для Lovable — DZ-6

Создай адаптивное веб-приложение на русском языке под названием
«BOOK·CRAFT — Создание сценариев».

## Стартовый экран

- Заголовок «Создание сценариев».
- Две большие карточки-кнопки:
  1. «Сценарий книги»;
  2. «Сценарий видеоролика».
- После выбора открывается основной рабочий экран.

## Основной экран

Экран разделён на две колонки. На экране телефона колонки располагаются друг
под другом.

### Обязательный dropdown

Над колонками размести dropdown «Выберите жанр» со значениями:

1. Фантастика;
2. Детектив;
3. Роман;
4. Комедия;
5. Триллер.

Выбранный жанр храни в состоянии React-компонента. Рядом всегда показывай
надпись `Текущий жанр: <выбранное значение>`. При смене dropdown состояние и
надпись должны сразу обновляться. Значение должно входить в данные, которые
передаются при запросе к backend.

### Левая колонка

- Заголовок «Чат — сценарий книги» либо «Чат — сценарий видеоролика».
- Список сообщений пользователя и AI.
- Поле с placeholder «Опишите идею, сюжет или задачу».
- Кнопка «Отправить».
- После отправки сообщение появляется в чате.
- Запрос отправляется методом POST на `/llm-api/v1/chat/completions` в формате,
  совместимом с OpenAI Chat Completions.

### Правая колонка

- Заголовок выбранного типа сценария.
- Три самостоятельных блока:
  - «Вступление»;
  - «Развитие»;
  - «Финал».
- Каждый блок содержит большое редактируемое textarea.
- После ответа AI обновляй содержимое этих трёх полей, но сохраняй возможность
  редактировать их вручную.

### Дополнительный блок базы знаний

Добавь раскрываемый блок «База знаний произведения». В нём должны быть:

- загрузка локальных TXT, MD и JSON;
- список добавленных источников с возможностью удалить файл;
- три режима: «Оригинальная история», «По мотивам», «Продолжение»;
- содержимое источников и выбранный режим должны передаваться вместе с запросом
  локальной модели;
- для MVP храни источники в localStorage, без внешней базы и облака.

## Дизайн

Сделай премиальный тёмный интерфейс литературной студии: глубокий графитовый
фон, фиолетовый акцент, мягкое свечение, тонкая сетка, крупная выразительная
типографика, аккуратные карточки и ясная иерархия. Не используй готовые
фотографии. Интерфейс должен хорошо работать на компьютере и телефоне.

Не подключай Supabase и не создавай внешнюю базу данных. Для демонстрации
используется локальный GigaChat по адресу `127.0.0.1:1234` через proxy Vite.
