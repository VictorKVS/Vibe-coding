# Распознавание в диктофоне

В текущий диктофон подключён локальный whisper.cpp. Микрофон и импорт MP3/WAV/M4A/OGG/WebM используют один процесс распознавания после декодирования браузером.

Нажмите «Распознать». Аудио преобразуется в моно WAV 16 кГц по 30 секунд. Процент показывает длительность успешно обработанных фрагментов, текст появляется постепенно. Во время первого фрагмента процент остаётся 0%, но отображается этап и прошедшее время. ETA появляется после первого готового фрагмента.

«Отменить» прерывает запрос и процесс Whisper; готовые фрагменты сохраняются. Повторный запуск продолжает с необработанного фрагмента. После изменения аудио требуется новое распознавание; прежний текст остаётся доступен для копирования до нового запуска. Текст можно скопировать или скачать как UTF-8 TXT.

Аудио передаётся только локальному сервису на 127.0.0.1:8019 через Vite proxy `/recorder-stt`. Сервис удаляет временное аудио и вывод Whisper после запроса. Текст и аудиобайты не включаются в диагностику. Сервер принимает один сегмент за раз, отклоняет WAV с неверными параметрами и ограничивает время обработки сегмента пятью минутами.

## Запуск

Штатный START_BOOKCRAFT_MEDIA.cmd теперь запускает также сервис распознавания. Отдельно: START_RECORDER_STT.cmd.

Локальная конфигурация `.runtime/recorder-stt.json` содержит пути `python`, `executable`, `model`. Она не хранится в Git. На этом компьютере используются уже установленные Python с FastAPI/Uvicorn и whisper.cpp с ggml-small.bin. При переносе проекта укажите существующие пути в конфигурации; `WHISPER_CPP_EXE` и `WHISPER_MODEL_PATH` переопределяют пути Whisper.

## Проверки

- npm test: поведение диктофона и STT, сегментация, прогресс, отмена, повтор, запоздавшие ответы, отсутствие текста в трассе.
- npm run build.
- tests/test_recorder_stt.py: проверка PCM и endpoint с имитацией процесса.
- Реальный Whisper: WAV 15 секунд обработан за 13.7 секунды, HTTP 200, получен русский текст.
- На открытой странице подтверждена реальная запись с микрофона 7.98 секунды: получен текст счёта от 1 до 10, 100%, обработка 8.08 секунды.

## Ограничения

Для длинных файлов браузер пока декодирует весь файл в память. Монтаж и экспорт больших записей могут занимать время. Сегменты распознаются независимо, поэтому слово на границе 30 секунд иногда требует ручной правки. Результат и состояние продолжения хранятся в памяти вкладки; сохраните TXT перед её закрытием. Качество распознавания зависит от записи и модели.
