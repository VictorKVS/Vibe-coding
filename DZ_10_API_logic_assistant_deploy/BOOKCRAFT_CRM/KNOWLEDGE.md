# База знаний для одного демо-диалога

Источник: `clinic-knowledge.mjs`. Врачи, цены и время из него использует сценарное ядро CRM. Полигон включает эту же базу системным сообщением на сервере при флажке «База знаний поликлиники». Кнопка «Взять диалог из базы» готовит проверку хирурга, послезавтра, имени и неизвестных условий ОМС. База и примеры видны в раскрывающемся блоке.

Все данные учебные. В базе нет реального адреса, правил ОМС или подготовки к приёму; их нельзя выдумывать. Если врач и день не определены, задать уточняющий вопрос. Сначала собрать данные, затем получить явное подтверждение. Создаётся только демо-заявка на согласование.

База ограничивает контекст модели, но сама по себе не гарантирует отсутствие выдумок. Для принятия результата просмотрите ответ и автоматические проверки. Основной секретарь по-прежнему работает по сценарию. В JSON каждого нового прогона сохраняется снимок базы для воспроизводимости.
