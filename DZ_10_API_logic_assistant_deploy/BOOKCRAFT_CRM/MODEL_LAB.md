# Полигон моделей

Открыть `http://127.0.0.1:5179/lab.html` или «Полигон моделей» в меню CRM.

- Список обнаруживает установленные модели Ollama (11434) и локального OpenAI-совместимого сервера (1234). Ключи и загрузка новых моделей не нужны.
- Выбрать одну или несколько моделей, задать правила секретаря, последовательность реплик и ожидаемые слова для каждого шага. Разделитель альтернатив — `|`. Пустая строка условия отключает проверку шага.
- Нажать «Прогнать сценарий»: модели обрабатываются последовательно, каждая получает одинаковые реплики и собственную историю ответов. Новый повтор начинает чистую историю. Максимум 10 шагов и 3 повтора.
- Сравнить среднее время и p95 до полного ответа, ошибки и совпадения слов. Под каждым ответом показаны токены, скорость генерации и время загрузки, когда провайдер возвращает эти значения.
- Остановить прогон можно в любой момент. Завершённые ответы сохраняются. История последних 10 прогонов доступна в списке; JSON содержит настройки и ответы.

Это настоящие ответы локальных LLM. Автоматические проверки слов не оценивают смысл, вежливость или безопасность — ответы нужно просматривать. Лимит 256 выходных токенов может обрезать длинные ответы, особенно рассуждающих моделей. Температура 0, seed 42; абсолютная повторяемость между разными движками не гарантируется. Первый ответ включает загрузку модели, последующие могут использовать кэш. p95 на трёх ответах фактически равен самому медленному; для устойчивых выводов нужны повторы.

Полигон не создаёт заявки и не отправляет сообщения клиентам. В основном диалоге CRM остаётся сценарный секретарь; выбор LLM пока действует внутри полигона. Для теста другой отрасли измените роль, каталог и реплики в редакторе. На GitHub Pages локальные API недоступны.

Метрики Ollama: [документация Chat API](https://docs.ollama.com/api/chat). Время запроса измеряется сервером CRM; токены/с рассчитываются по `eval_count / eval_duration`. TTFT не измеряется, поскольку ответ запрашивается без стриминга.

## Первый проверочный прогон

На трёх репликах клиники: Qwen 2.5 Coder 1.5B — среднее 4,27 с, совпадение условий 2/3; Llama 3.2 1B — 10,88 с, 1/3. Оба прогона без ошибок API. Первые ответы включали загрузку 12,006 и 14,190 с. Это один пробный прогон, не рейтинг моделей.
