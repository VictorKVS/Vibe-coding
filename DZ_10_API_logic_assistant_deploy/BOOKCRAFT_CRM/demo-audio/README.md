# Учебные аудиозаписи

Синтезированы Microsoft Irina Desktop на Windows для имитации обращений к терапевту, кардиологу и на профилактический осмотр. Это не настоящие обращения пользователя за медицинской помощью.

`recognition-results.json` содержит фактические ответы локального Whisper на эти файлы и измеренное время. OGG/Opus-файл создан из первой записи для тестирования формата Telegram. Он не получен от реального Telegram-пользователя.
