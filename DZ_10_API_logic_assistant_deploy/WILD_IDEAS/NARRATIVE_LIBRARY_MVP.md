# Narrative Library MVP

Цель: превратить «Дикие идеи» из генератора текста в интерактивный конструктор сюжета. Алина предлагает проверенные драматургические механики, человек принимает/отклоняет их, а выбранные элементы складываются в `STORY DNA` проекта.

## Жанровые полки MVP

1. `Фантастика / киберпанк`
2. `Шпионский боевик`
3. `Фэнтези / приключение`
4. `Детектив / тайна`

Каждая полка сейчас содержит 6 рабочих модулей. Это демонстрационный корпус; он рассчитан на расширение до сотен и тысяч карточек.

## Карточка механики

Для каждого элемента библиотеки храним:

```text
id
genre
title
purpose
mechanic
source_title
source_author
source_year
source_type
comparable_projects[]
fit_dimensions[]
limitations[]
rights_status
notes
```

### Важное правило

`FIT SCORE` — не вероятность коммерческого успеха и не прогноз выручки. Это объяснимая оценка совместимости выбранной драматургической механики с текущим замыслом. Для реальной аналитики отдельными слоями подключаются аудитория, продажи, рейтинги, бюджеты, территория и дата.

## Как добавлять схемы пользователя

Для каждой найденной памятки/схемы:

1. Не переносить картинку в продукт автоматически.
2. Определить, есть ли право на публикацию изображения.
3. Извлечь саму методику в структурированную карточку.
4. Указать источник и ограничения.
5. Нарисовать собственную интерактивную схему средствами сайта.
6. Привязать 3–10 сопоставимых произведений/проектов.
7. Проверить, что механика не превращается в копирование конкретного сюжета.

## Следующие наборы для наполнения

### Фантастика
- технологии и их последствия
- контакт с неизвестным
- социальные модели будущего
- военная академия
- наследие и артефакты
- расширяющаяся вселенная
- древние цивилизации

### Шпионский боевик
- миссия с неполной информацией
- двойной агент
- куратор
- предательство
- ограничение по времени
- смена цели
- цена лояльности

### Фэнтези
- переход порога
- магия с ограничениями
- реликвия
- испытания достоинства
- путешествие
- спутники
- неполная легенда

### Детектив
- загадочное событие
- честная цепочка улик
- ложная гипотеза
- скрытый мотив
- алиби
- временная линия
- реконструкция
- цена раскрытой правды

## UX

Пользователь не видит библиотеку как каталог из тысячи карточек. Алина по контексту достаёт 5–8 релевантных механизмов и размещает их вокруг себя. Пользователь может:

- раскрыть механику;
- увидеть назначение и краткую логику;
- включить/исключить её;
- посмотреть источники и аналоги;
- увидеть изменение `FIT SCORE`;
- свернуть выбранное в `STORY DNA`.

После упаковки `STORY DNA` сохраняется в памяти проекта и используется при выборе мира, персонажей, сцен и дальнейшей генерации.
