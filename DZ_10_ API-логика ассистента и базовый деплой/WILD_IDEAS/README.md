# WILD_IDEAS

Актуальный пилот «Дикие идеи» для задания 10.

[Сайт](https://wild-ideas-pilot.cocmosxx2.chatgpt.site/) · [Описание задания и запуск](../README.md) · [Статус](../STATUS.md)

Запуск: `npm ci`, затем `npm run dev`. Сборка: `npm run build`. Node.js >= 22.13.

Доступ к опубликованному сайту — только владельцу. Диалог подготовлен заранее; изображения миров и персонажей — готовые концепты. Генератор комикса и приём заказов ещё не подключены.
