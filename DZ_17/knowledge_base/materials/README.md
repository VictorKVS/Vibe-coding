# Source materials workspace

Этот каталог резервирует физическое место для исходных материалов Universal Knowledge Base.

## Структура

```text
materials/
├── README.md
├── originals/                    # локальные оригиналы, по умолчанию не коммитятся
├── extracts/                     # наши структурированные извлечения и конспекты
└── indexes/                      # производные поисковые индексы
```

## Правила

1. Полный текст книги/стандарта помещается в `originals/<SOURCE_ID>/` только при законном наличии файла и разрешённом использовании.
2. Сам факт регистрации источника в `source_registry.v1.json` не означает, что оригинал физически присутствует.
3. Для каждого обработанного оригинала фиксируются `source_file_path`, `source_hash_sha256`, `acquisition_uri`, `accessed_at` и точный `source_locator`.
4. В `extracts/<SOURCE_ID>/` хранятся наши собственные структурированные записи, например `structure-map.md`, `extraction-notes.md`, `knowledge-records.jsonl`.
5. В `indexes/<SOURCE_ID>/` разрешены только производные данные, которые можно полностью восстановить из канонического источника и извлечений.
6. Агенты не получают собственные копии материалов; они обращаются к общей KB по canonical ID.

Полные правила: `../PROVENANCE_AND_STORAGE_POLICY.md`.
Физическая карта: `../PHYSICAL_MAP.md`.
