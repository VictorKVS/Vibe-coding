# Контрольный пример: «Программист»

Этот каталог — накопительный эталонный пример для проверки кодексов Specialist Factory.

Исходный запрос: **«Программист»**.
Контекст пилота: Российская Федерация; текущее состояние исследуется на дату запуска.

Правила:
- пример пополняется по мере прохождения C01-I01…C01-I16 и следующих кодексов;
- факт, claim, inference и UNKNOWN не смешиваются;
- связанные названия не считаются синонимами без доказательства;
- evidence-кандидаты C01 не считаются окончательно верифицированными до C02;
- старые версии источников сохраняются;
- отсутствие доказательства не превращается в отрицательный факт.

## Текущий прогресс

- C01-I01 — создан рабочий пример идентичности профессии.
- C01-I02…C01-I16 — ещё не выполнены.
- C02+ — ещё не выполнены.
