# Programmer Knowledge Model

Status: DRAFT v0.1

«Программист» является первым контрольным специалистом для Specialist Factory. Этот файл применяет общую Specialist Knowledge Runtime Practice к конкретной профессии.

## Конструкция

PROGRAMMER CONTEXT
→ applicable law
→ applicable ГОСТ/ISO/IEC/standards
→ professional standard / functions
→ international professional model
→ education corpus
→ scientific/technical knowledge
→ engineering practice
→ experience bank
→ independent exams
→ qualification state.

Ни один слой не должен механически копироваться в компетенции. Каждый переход должен иметь evidence и provenance.

## Education corpus

Программы сильных мировых школ используются как evidence о структуре подготовки человека, а не как автоматический профессиональный стандарт.

Для каждой программы сохраняются:
institution → program/version → course → topics → learning outcomes → prerequisites → assessment → competency candidates.

Конкретный язык или инструмент не становится обязательным только потому, что его использует сильная программа. Сначала определяется формируемая способность и проверяется её повторяемость и профессиональная применимость.

## Programmer runtime

При решении задачи программист:
1. классифицирует задачу;
2. определяет необходимые компетенции и ограничения;
3. запрашивает Programmer KB;
4. получает Evidence Pack;
5. формирует профессионально значимый decision step;
6. проверяет его по требованиям, KB и предыдущим шагам;
7. фиксирует contradictions/UNKNOWN;
8. продолжает решение;
9. выполняет финальную consistency validation;
10. выдаёт результат с трассировкой оснований.

## Qualification

Компетенция программиста подтверждается не наличием материала в RAG, а прохождением:
knowledge check → controlled exercise → typical practical task → project/case → unseen transfer task → independent evaluation → regression.
