# ДЗ-17 · Test Plan

## Цель

Проверить, что ALINA действительно выполняет мультимодальный сценарий `текст + изображение`, а интерфейс остаётся стабильным и предсказуемым.

## Acceptance Criteria

| ID | Проверка | Ожидаемый результат | Статус |
|---|---|---|:---:|
| T01 | Открытие приложения | UI загружается без критической ошибки | ⏳ |
| T02 | Загрузка JPG/PNG | изображение появляется в Preview | ⏳ |
| T03 | Текстовый запрос | запрос принимается интерфейсом | ⏳ |
| T04 | Фото + текст | модель получает оба входа в одном сценарии | ⏳ |
| T05 | Наблюдения | ALINA отдельно показывает, что непосредственно видно | ⏳ |
| T06 | Интерпретация | творческие выводы отделены от наблюдения | ⏳ |
| T07 | 3 варианта | выдаются ровно три разных варианта | ⏳ |
| T08 | Human-in-loop | ALINA ждёт выбора пользователя | ⏳ |
| T09 | Ошибочное изображение | понятное сообщение об ошибке | ⏳ |
| T10 | Пустой запрос | интерфейс не падает | ⏳ |
| T11 | Mobile | элементы не перекрываются | ⏳ |
| T12 | Secrets | реальные ключи отсутствуют во frontend/repo | ⏳ |

# Контрольные сценарии

## S1 · Базовый мультимодальный анализ

**Вход:** фотография + запрос:

> Проанализируй этот визуальный референс для сцены книги. Что из изображения можно использовать и предложи три разных направления.

**Ожидается:**

- распознанные элементы;
- интерпретация в контексте книги;
- три варианта;
- сильная сторона и риск;
- запрос выбора автора.

## S2 · Изображение без пояснения

**Вход:** только фото.

**Ожидается:** ALINA может кратко описать наблюдаемое, но не должна придумывать назначение картинки. Она предлагает пользователю указать задачу.

## S3 · Текст без изображения

**Вход:**

> Мне нужен визуальный референс для боевой академии.

**Ожидается:** приложение не падает; ALINA либо работает как текстовый продюсер, либо просит загрузить визуальный референс для мультимодального анализа.

## S4 · Противоречие между фото и текстом

**Вход:** изображение спокойной дневной сцены + текст:

> На этом фото ночная битва в разрушенном городе.

**Ожидается:** ALINA явно сообщает, что описание пользователя не соответствует наблюдаемым признакам, и не выдаёт утверждение пользователя за содержимое изображения.

## S5 · Проверка creative-control

**Вход:** любое изображение + творческая задача.

**Ожидается:** после трёх вариантов ALINA не продолжает выбранный сюжет самостоятельно, пока пользователь не нажал/указал вариант.

---

# Edge Cases

- очень большое изображение;
- неподдерживаемый формат;
- повреждённый файл;
- очень длинный текст;
- пустой текст;
- несколько объектов на изображении;
- изображение, не связанное с запросом;
- повторная загрузка другого изображения;
- повторный анализ после выбора варианта.
