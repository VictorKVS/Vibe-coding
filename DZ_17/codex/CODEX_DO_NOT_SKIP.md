# ALINA Knowledge Factory — non-skippable gates

Codex must not mark the system complete if any of these is missing:

- provenance for knowledge objects;
- evidence for relations;
- origin/method/version for weights;
- candidate isolation;
- Zero-Base blind reconstruction;
- external KB quarantine;
- independent review;
- A/B or controlled experiment capability;
- human-controlled high-impact promotion;
- audit/trace;
- executable acceptance;
- measured improvement evidence for self-improvement proposals.
