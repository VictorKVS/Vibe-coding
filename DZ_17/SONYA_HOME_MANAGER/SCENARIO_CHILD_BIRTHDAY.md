# Сценарий MVP · Детский праздник

## Цель

Показать преподавателю ДЗ-17 реальный мультимодальный поток на понятном бытовом кейсе.

## Вход

Пользователь передаёт:

- фото продуктов / праздничного стола / комнаты / декора;
- текстовый запрос;
- при необходимости число гостей, возраст ребёнка, бюджет и временные ограничения.

Пример запроса:

> У сына день рождения. Будет 12 детей. Праздник дома с 15:00 до 19:00. Проанализируй фото, скажи, что уже можно использовать, предложи меню и декор, составь список покупок и план подготовки. Отдели то, что действительно видно, от предположений.

## Ожидаемый ответ

### Наблюдения

Только то, что видно на фото.

### План праздника

- уборка;
- декор;
- гости;
- меню;
- торт;
- напитки;
- развлечения;
- подарки;
- завершение и уборка после праздника.

### Тайминг

```text
10:00 подготовка дома
12:00 доставка / закупки
14:00 сервировка
15:00 гости
15:30 игры
17:00 еда / торт
18:00 подарки
19:00 завершение
```

### Покупки

Только недостающие позиции, с возможностью добавить вручную.

### Бюджет

```text
План
Факт
Остаток
```

## Что должно быть видно на финальном скриншоте ДЗ-17

1. загруженное изображение;
2. исходный текстовый запрос;
3. ответ Сони;
4. минимум одна карточка плана / меню / покупок;
5. trace выбранной модели;
6. latency;
7. название сценария «Детский праздник».

## Acceptance

- [ ] изображение загружается;
- [ ] текст обязателен;
- [ ] image + text уходят одним multimodal-запросом;
- [ ] модель действительно поддерживает vision;
- [ ] наблюдение отделено от предположения;
- [ ] план можно превратить в UI-карточки;
- [ ] пользователь может подтвердить или изменить решение;
- [ ] при отсутствии реальной vision-модели DEMO не притворяется анализом пикселей.
