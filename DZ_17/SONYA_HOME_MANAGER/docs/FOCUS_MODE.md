# SONYA Focus Mode

## Назначение

Focus Mode увеличивает важные текстовые блоки поверх основного интерфейса, чтобы результат анализа было удобно читать и показывать на демонстрации.

## Карточки результата

Клик по карточкам:

- «Что видно точно»;
- «Что предполагаю»;
- «Как приготовить / что сделать»;
- «Безопасность и замены»

открывает полноэкранный glass-overlay.

Поведение:

- основной сайт размывается и затемняется;
- карточка визуально вырастает примерно из масштаба 1/3 до полного размера;
- текст увеличивается примерно в 2.5–3 раза относительно компактной карточки;
- окно остаётся полупрозрачным;
- пункты получают крупную нумерацию;
- закрытие: кнопка X, Esc или клик по фону.

## Детский голосовой режим

После нажатия «Режим готовки» стандартный Cooking Coach автоматически получает большой Focus-overlay.

Экран делится на две части:

### Слева — алгоритм

- все шаги приготовления;
- крупные визуальные узлы и emoji;
- завершённые, текущий и будущие шаги имеют разные состояния;
- текущий шаг подсвечивается;
- вертикальная линия показывает последовательность.

### Справа — текущий шаг

- крупный номер шага;
- крупная инструкция;
- короткое детское пояснение;
- кнопки «Назад», «Повторить/Стоп», «Дальше»;
- прогресс выполнения в процентах.

Для потенциально опасных действий интерфейс напоминает, что горячее и нож используются со взрослым.

## Архитектура

Focus Mode реализован как UI-надстройка:

```text
App.tsx
  ↓ существующие DOM-карточки / Cooking Coach
FocusEnhancer.tsx
  ↓ event delegation + MutationObserver
FocusMode.tsx
  ↓ React portals
focus-mode.css
```

Это позволяет не вмешиваться в AI-пайплайн, Agent Trace и основную логику SONYA.

## Адаптивность

На desktop окно занимает до 94–96% viewport и сохраняет двухколоночную схему алгоритма.

На мобильном алгоритм перестраивается в одну колонку, а элементы управления располагаются вертикально.
