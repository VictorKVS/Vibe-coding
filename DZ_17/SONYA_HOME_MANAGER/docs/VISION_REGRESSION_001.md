# SONYA Vision Regression 001 — детская паста

Контрольный сценарий для регрессионного теста Vision/RAG.

## Цель

Проверять, что изменения prompt/RAG/model stack не ухудшают базовое распознавание фигурной детской подачи.

## Ожидаемые физические наблюдения

- тарелка имеет бирюзовый / cyan-turquoise оттенок, а не должна автоматически называться просто голубой;
- в нижней половине расположены длинные светло-жёлтые нити пасты/спагетти;
- над пастой расположена цепочка круглых розовых ломтиков примерно одинакового диаметра;
- сверху расположен насыщенно-оранжевый плоский элемент;
- от него радиально отходят тонкие оранжевые полоски;
- присутствуют зелёные тонкие веточки/перистая зелень.

## Ожидаемые предположения

- длинная паста — спагетти;
- круглые розовые ломтики — сосиска или другое варёное колбасное изделие;
- насыщенно-оранжевые элементы по цвету и форме больше всего похожи на морковь;
- зелень похожа на укроп;
- цепочка круглых элементов напоминает гусеницу;
- оранжевая радиальная композиция напоминает солнце.

## Недопустимые ошибки

- «картофельная нарезка» для ярко-оранжевого кружка и тонких полосок без дополнительных визуальных признаков картофеля;
- «тип картофеля» как отдельное предположение;
- «нарезанные спагетти», если видны длинные непрерывные нити;
- пустой пункт `-`;
- перенос художественных образов `солнце/гусеница/лицо` в блок физических фактов;
- смешение мер безопасности с приготовлением;
- общий вариант меню `Фигурное блюдо` без конкретики.

## Acceptance

PASS, если:

1. `physical` содержит минимум 4 содержательных пункта;
2. оттенок тарелки классифицирован как бирюзовый/близкий сине-зелёный;
3. морковь имеет приоритет над обычным картофелем;
4. распознаны паста и круглые розовые ломтики;
5. нет пустых пунктов и дублей;
6. FAST формирует содержательные preparation/menu/shopping/safety без второго LLM.
