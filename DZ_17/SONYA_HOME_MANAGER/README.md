# ДЗ-17 · СОНЯ — Домовой управляющий

> Мультимодальный AI-помощник для дома и семьи. Учебный сценарий ДЗ-17: **детский праздник**.

## Идея

СОНЯ — не просто AI-Кулинар. Это домашний управляющий, который объединяет:

- дом и уборку;
- закупки и списки;
- счета и напоминания;
- семейные события, дни рождения и годовщины;
- кулинарию и умный холодильник;
- предпочтения семьи и образ жизни;
- мультимодальный анализ `image + text`;
- позже — голос.

Для ДЗ-17 основной демонстрационный поток остаётся простым и проверяемым:

```text
ФОТО / ВИЗУАЛЬНЫЙ КОНТЕКСТ
        +
ТЕКСТОВЫЙ ЗАПРОС
        ↓
SONYA MULTIMODAL GATEWAY
        ↓
VISION / LLM
        ↓
НАБЛЮДЕНИЕ
        ↓
ПЛАН ДЕЙСТВИЙ
        ↓
ЧЕК-ЛИСТ + МЕНЮ + ПОКУПКИ + БЮДЖЕТ
        ↓
ПОДТВЕРЖДЕНИЕ ЧЕЛОВЕКА
```

## Демонстрационный сценарий

**Детский день рождения сына.**

СОНЯ должна уметь собрать единый план:

1. кто участвует и сколько гостей;
2. дата, время и место;
3. уборка и подготовка дома;
4. меню с учётом предпочтений и ограничений;
5. что уже есть дома / в холодильнике;
6. что требуется докупить;
7. торт, декор, свечи, одноразовая посуда;
8. аниматор / развлечения;
9. подарки;
10. расписание дня;
11. плановый и фактический бюджет;
12. напоминания и статусы задач.

## Главное правило

```text
НАБЛЮДЕНИЕ ≠ ПРЕДПОЛОЖЕНИЕ ≠ РЕШЕНИЕ ПОЛЬЗОВАТЕЛЯ
```

СОНЯ должна отделять то, что действительно извлечено из фото/данных, от предположений и рекомендаций.

## Архитектура MVP

```text
Web UI
  ↓
/api/sonya
  ↓
Orchestrator
  ├── Multimodal model
  ├── Household profile
  ├── Fridge inventory
  ├── Event planner
  ├── Shopping list
  ├── Bills/reminders
  └── Audit / trace
```

На первом этапе не нужен тяжёлый «зоопарк» из десятков моделей. Для сдачи используется минимальный рабочий набор, описанный в [`MODEL_ZOO.md`](MODEL_ZOO.md).
