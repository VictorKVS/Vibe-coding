# SONYA app

Здесь будет рабочее web-приложение ДЗ-17.

Первый этап реализации:

1. Next.js/React UI в glassmorphism-стилистике;
2. hero с анимируемой Соней;
3. сценарий «Детский праздник»;
4. загрузка изображения;
5. текстовый запрос;
6. server-side `/api/sonya`;
7. локальный llama.cpp multimodal provider;
8. карточки: план, меню, покупки, бюджет;
9. model trace + latency;
10. production build и public deploy.

Не хранить модели, секреты и runtime binaries в Git.
