# SONYA Food Vision Grounding KB v2

Назначение: помочь текстовому аналитику корректно интерпретировать результат vision-модели. Эта база НЕ заменяет анализ изображения и не должна использоваться для выдумывания невидимых ингредиентов.

## 1. Четыре уровня знания

Всегда разделяй:

1. **Видно точно** — непосредственно наблюдаемое: цвет, форма, расположение, количество, размер, текстура, геометрия композиции и только очевидный класс продукта.
2. **Вероятно** — интерпретация или предположение: «похоже на сосиску», «вероятно морковь», «напоминает солнце/лицо/гусеницу».
3. **Нельзя установить по фото** — состав, марка, вид мяса, наличие сахара, соли, масла, аллергенов, способ термообработки, свежесть внутри продукта и т. п.
4. **Рекомендация / действие** — рецепт, замена, безопасность, закупка, способ приготовления. Это никогда не является наблюдением.

### Жёсткое правило для `observation`

В `observation` запрещены слова и конструкции:

- «похоже»;
- «вероятно»;
- «возможно»;
- «может быть»;
- «напоминает»;
- «скорее всего»;
- «похожий на».

Если такая конструкция нужна, весь пункт должен находиться в `assumptions`.

Пример:

- observation: «в центре тарелки расположен оранжевый круглый элемент с тонкими оранжевыми полосками вокруг»;
- assumptions: «композиция напоминает солнце»;
- assumptions: «оранжевые элементы, вероятно, сделаны из моркови».

## 2. Общие правила качества

- Пиши только по-русски.
- Не повторяй одну мысль разными словами.
- Один объект изображения описывай один раз.
- Не используй бессмысленные шаблонные фразы вроде «может быть заменяем на безопасные альтернативы».
- Не называй один объект несколькими взаимоисключающими продуктами без явного указания неопределённости.
- Не превращай фон, тарелку, салфетку или декор в ингредиенты.
- Не считай форму доказательством состава продукта.
- Не придумывай способ приготовления исходного блюда по внешнему виду.
- Не выдавай «солнце», «лицо», «бабочку», «червяка», «гусеницу» и другие смысловые образы за физический факт: это интерпретация композиции.

## 3. Типовые визуальные признаки еды

### Паста / спагетти

Признаки: длинные тонкие светло-жёлтые нити, собранные в пучок или клубок.

Допустимо:
- «видны длинные тонкие нити варёной пасты»;
- при высокой уверенности — «видны спагетти».

Нельзя утверждать по одному фото:
- сорт пшеницы;
- наличие яйца;
- точный состав соуса;
- соль или масло.

### Сосиска / колбасное изделие

Признаки: гладкие розовые/бежево-розовые круглые ломтики одинакового диаметра, иногда с оболочкой по краю.

Observation:
- «видна цепочка круглых розовых ломтиков одинакового диаметра».

Assumptions:
- «ломтики похожи на сосиску или другое варёное колбасное изделие».

Нельзя определять по фото:
- вид мяса;
- марку;
- состав;
- содержание соли/нитритов.

### Морковь

Признаки: насыщенный оранжевый цвет, плотная однородная текстура, плоские ломтики или палочки.

Observation:
- «виден оранжевый круглый элемент и несколько тонких оранжевых полосок вокруг».

Assumptions:
- «элементы, вероятно, сделаны из моркови»;
- «композиция напоминает солнце».

### Зелень / укроп

Признаки укропа: тонкие нитевидные/перистые листья ярко-зелёного цвета.

Observation:
- «видны тонкие зелёные веточки/листья».

Assumptions:
- «по форме зелень похожа на укроп».

## 4. Детские блюда и фигурная подача

Отдельно описывай:

- физические элементы;
- вероятные ингредиенты;
- художественную интерпретацию композиции.

Правильное разделение:

- observation: «в нижней части тарелки лежат две порции длинной пасты»;
- observation: «над ними выложена цепочка круглых розовых ломтиков»;
- assumptions: «розовые ломтики похожи на сосиску»;
- assumptions: «вся композиция напоминает гусеницу/персонажа»;
- observation: «сверху расположен оранжевый круглый элемент с радиально расходящимися полосками»;
- assumptions: «эта часть композиции напоминает солнце и, вероятно, сделана из моркови».

Не называй спагетти «фигуркой», если фигурная форма создана всей композицией.

## 5. Приготовление

`preparation` содержит только действия по реконструкции блюда.

Не помещай сюда:
- проверки аллергенов;
- предупреждения об ожогах;
- рекомендации по размеру кусочков для детей;
- общие меры безопасности.

Если продукт определён неуверенно, действие должно сохранять неопределённость.

Плохо:
- «разогрейте сосиски».

Хорошо:
- «если розовые ломтики действительно являются сосиской/колбасным изделием, подготовьте их согласно инструкции на упаковке».

Не утверждай способ приготовления, которого не видно на фото.

## 6. Безопасность

`safety` содержит только релевантные меры безопасности и ограничения.

Допустимо:
- учитывать заявленные аллергии;
- проверять состав готовых мясных изделий на упаковке;
- проверять температуру горячей еды перед подачей;
- адаптировать размер и текстуру плотных круглых кусочков для маленьких детей.

Не дублируй эти пункты в `preparation`.

Не утверждай наличие аллергена, если состав продукта неизвестен.

## 7. Рецепт и закупка

Рецепт — реконструкция, а не факт изображения.

Если видны паста + круглые розовые ломтики + оранжевые элементы + зелень, можно предложить базовую реконструкцию, но явно отделять визуально подтверждённое от вероятного состава.

Количество продуктов для гостей указывай как ориентировочное с учётом возраста и наличия других блюд.

## 8. Menu

`menu` не должен быть пустым, если пользователь просит идеи блюда/праздничное меню.

Дай 1–3 разумных варианта, основанных на увиденной композиции.

Не добавляй блюда, которые никак не связаны с изображением или запросом.

## 9. Структура финального ответа

### observation
Только уникальные физические наблюдения. 3–7 пунктов. Без слов неопределённости и без интерпретации образов.

### assumptions
Только реальные предположения, вероятные ингредиенты и смысловая интерпретация композиции. 0–5 пунктов.

### preparation
Только практические шаги реконструкции блюда. 3–8 шагов.

### menu
1–3 разумных варианта, если пользователь просит идеи/праздник.

### shoppingList
Конкретные продукты и ориентировочные количества на указанное число гостей.

### safety
Только релевантные меры безопасности/ограничений. 1–4 пункта.

## 10. Контроль перед выдачей

Перед финальным JSON проверь:

- нет ли одинаковых пунктов внутри и между разделами;
- нет ли английских/испанских слов;
- `observation` не содержит «похоже», «вероятно», «напоминает» и советов;
- смысловые образы («солнце», «лицо», «бабочка», «гусеница») находятся в `assumptions`, если это не буквальный физический объект;
- `preparation` не содержит мер безопасности;
- `safety` не дублирует `preparation`;
- предположения не выданы за факты;
- рецепт опирается на vision-отчёт;
- покупки соответствуют числу гостей;
- `menu` не пуст, если пользователь просил варианты;
- все строки содержательны и конкретны.
