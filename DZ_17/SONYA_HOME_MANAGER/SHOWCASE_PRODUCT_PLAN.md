# SONYA Showcase / Portfolio Plan

## Цель

После сдачи ДЗ-17 SONYA развивается как витринный продукт для портфолио: premium household AI, а не учебный интерфейс.

## Showcase Definition of Done

1. Первый экран выглядит как коммерческий premium SaaS.
2. Каждый пункт левого меню открывает рабочий MVP-сценарий.
3. Общий семейный контекст используется между модулями.
4. AI-функции отделены от demo/локальных действий.
5. Никаких ложных заявлений об оплате, заказе или бронировании.
6. Desktop-first + tablet/mobile responsive.
7. Витринный сценарий можно показать за 60–120 секунд.
