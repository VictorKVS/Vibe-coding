# Nepal MVP — эталонная страна для AI Travel Premium

## Цель

Полностью отработать на Непале весь сценарий Telegram-бота: анкету, подбор тура, проверенные цены, RAG-базу знаний, AI-консультанта, анализ отзывов, галерею и Marketing Designer AI.

## Жесткое правило данных

LLM не имеет права придумывать цены, даты, наличие мест, звездность, состав пакета или рейтинг. Эти данные берутся только из структурированной базы данных. Если данных нет, бот сообщает, что информации недостаточно или требуется проверка.

## Сценарий пользователя

1. /start
2. Главное меню
3. Подобрать тур с нуля / Есть идея
4. FSM собирает: взрослые, дети, возраст детей, отель, даты, бюджет, тип отдыха, направление
5. Экран подтверждения параметров
6. Поиск по базе туров
7. Экран «Найдено N вариантов»
8. Карточка тура
9. Кнопки Telegram: выбрать, подробнее, галерея, спросить AI, следующий
10. Галерея Непала
11. Travel Expert AI отвечает по Непалу с RAG + проверенными операционными данными
12. Пользователь может оставить заявку менеджеру

## База знаний Непала

Рекомендуемые разделы:
- overview.md — общая информация
- climate.md — климат и сезоны
- attractions.md — достопримечательности
- food.md — кухня
- souvenirs.md — что привезти
- safety.md — бытовые советы и безопасность
- transport.md — транспорт
- trekking.md — треккинг и высотные маршруты
- reviews.md — демонстрационный набор отзывов и их разбор
- faq.md — частые вопросы

## Операционные данные

Храним отдельно от RAG:
- туры
- цены
- даты
- отели
- питание
- состав пакета
- доступность
- рейтинг
- дата обновления

## Marketing Designer AI

Для Непала использует только данные выбранного тура из базы. На вход получает структурированный JSON и формирует рекламную карточку/промпт с логотипом AI Travel Premium, названием тура, длительностью, звездностью и проверенной ценой.

## Критерий готовности Nepal MVP

Непал считается полностью реализованным, когда пользователь может пройти весь путь от /start до заявки менеджеру, открыть галерею, получить ответы Travel Expert AI по базе знаний и увидеть рекламную карточку, в которой цена и параметры совпадают с записью в базе.
