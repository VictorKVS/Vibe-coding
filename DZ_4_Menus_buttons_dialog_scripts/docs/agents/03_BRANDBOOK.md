# AI Travel Premium — BrandBook MVP

## Бренд

Название: **AI Travel Premium**

Позиционирование: современный премиальный AI-сервис для подбора и презентации путешествий.

## Визуальный язык

Основные признаки:

- темно-синий / navy фон;
- золотые акценты;
- белая типографика;
- насыщенные туристические фотографии;
- чистая композиция;
- премиальный, но не перегруженный стиль;
- единая визуальная система для всех направлений.

## Логотип

На визуалах используется надпись **AI TRAVEL PREMIUM** и фирменный символ глобуса/самолета.

Логотип не должен:

- дублироваться несколько раз;
- менять цветовую схему между карточками;
- занимать основную часть изображения.

## Telegram Screens

Статические экраны Telegram должны содержать:

- фирменный фон или тематическую фотографию;
- логотип;
- короткий заголовок;
- при необходимости краткую подсказку;
- визуальный запас пространства под сообщение и InlineKeyboard.

Не допускается рисовать внутри изображения:

- кнопки Telegram;
- клавиатуру;
- стрелки навигации;
- поле ввода;
- фальшивые переключатели;
- браузерные меню;
- мобильную рамку устройства, если она не нужна для презентации.

## Tour Cards

Карточка тура может содержать:

- логотип;
- номер тура;
- название направления;
- флаг;
- узнаваемый пейзаж или достопримечательность;
- слоган;
- рейтинг;
- даты;
- туристов;
- отель;
- питание;
- город вылета;
- цену;
- перечень включенных услуг.

Не рисовать:

- «Выбрать тур»;
- «Подробнее»;
- «Галерея»;
- «Назад»;
- «Следующий».

Эти элементы создаются настоящими Telegram InlineKeyboardButton.

## Галерея

Галерейные изображения должны быть чистыми фотографиями без интерфейсных элементов и текста.

Пример структуры:

```text
assets/gallery/nepal/
├── photo1.jpg
├── photo2.jpg
├── photo3.jpg
├── photo4.jpg
├── photo5.jpg
└── photo6.jpg
```

## Контроль качества

Перед сохранением визуала необходимо проверить:

- соответствует ли он фирменной палитре;
- нет ли нарисованных кнопок;
- нет ли случайных функций, которых нет в проекте;
- совпадают ли цена и характеристики с входными данными;
- узнаваемо ли направление;
- читается ли текст;
- не перегружена ли композиция.
