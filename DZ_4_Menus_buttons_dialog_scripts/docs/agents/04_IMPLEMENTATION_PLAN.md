# План реализации двух AI-агентов

## Этап 1 — Travel Expert AI

1. Подготовить структуру `knowledge/`.
2. Добавить стартовые знания по 3–5 направлениям.
3. Создать загрузчик документов.
4. Добавить embeddings и поиск по знаниям.
5. Реализовать функцию `retrieve_context()`.
6. Реализовать system prompt агента.
7. Передавать в агента данные FSM и выбранного тура.
8. Добавить память диалога в рамках сессии.
9. Добавить анализ отзывов.
10. Добавить защиту от выдумывания актуальных данных.

## Этап 2 — Travel Marketing Designer

1. Подключить BrandBook.
2. Создать JSON-схему данных тура.
3. Реализовать генератор image prompt.
4. Добавить режим `telegram_screen`.
5. Добавить режим `telegram_ad`.
6. Реализовать проверку, что в изображение не закладываются Telegram-кнопки.
7. Сохранять метаданные результата.
8. В дальнейшем подключить генератор изображений через API.

## Этап 3 — Telegram Integration

1. Главное меню.
2. FSM анкеты.
3. Подтверждение параметров.
4. Выдача карточек туров.
5. Inline-навигация.
6. MediaGroup для галереи Непала.
7. Кнопка «Спросить AI» → Travel Expert AI.
8. Кнопка «Выбрать тур» → контакт пользователя.
9. Сохранение заявки.

## Этап 4 — Colab

Цель: преподаватель открывает одну ссылку, добавляет Secrets и запускает все ячейки.

Secrets MVP:

```text
TG_TOKEN2
GIGACHAT_CREDENTIALS
```

Colab должен автоматически:

- установить зависимости;
- подготовить папки;
- получить или восстановить ассеты;
- создать локальную базу;
- инициализировать RAG;
- запустить Telegram polling.

## Этап 5 — Проверка

Минимальный сценарий приемки:

```text
/start
→ Подобрать с нуля
→ пройти анкету
→ подтвердить параметры
→ увидеть найденные туры
→ открыть Непал
→ открыть галерею
→ задать вопрос Travel Expert AI
→ выбрать тур
→ отправить контакт
→ получить сообщение об успешной заявке
```

## Что сознательно не входит в MVP

- полноценная CRM;
- PostgreSQL в Colab;
- Django API;
- Docker Compose;
- онлайн-платежи;
- PDF-коммерческое предложение;
- мультиязычность;
- динамическая генерация всех 17 карточек в реальном времени.

Эти функции могут быть добавлены после сдачи базового проекта.
