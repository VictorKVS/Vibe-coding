# Nepal Knowledge Pack

Этот каталог содержит проверяемую базу знаний Travel Expert AI по Непалу.

## Разделы

- `overview.md` — общая информация о направлении
- `climate.md` — климат, сезоны и погодные особенности
- `attractions.md` — основные достопримечательности
- `food.md` — кухня и блюда
- `souvenirs.md` — что можно привезти
- `transport.md` — особенности перемещения
- `trekking.md` — треккинг и высотные маршруты
- `reviews.md` — отзывы и демонстрационный анализ
- `faq.md` — частые вопросы

## Правило использования

RAG используется для справочных знаний. Цены, даты, наличие, параметры отеля и состав тура берутся только из `data/tours.csv`/SQLite и не должны генерироваться LLM.
