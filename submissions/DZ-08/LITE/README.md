# ДЗ-8 / LITE — загрузка изображения

Отдельная карточка сдачи задания 2212 Lite. Реализация встроена в BOOK·CRAFT и не смешивает доказательства ДЗ-6 и ДЗ-8.

## Результат

Пользователь прикрепляет PNG, JPEG или WEBP. После успешного выбора файла в верхнем левом углу связанного с ним блока появляется зелёный статус **«Фото загружено»**. После удаления изображения статус исчезает.

## Матрица приёмки

| Требование | Реализация | Проверка |
|---|---|---|
| Принять изображение на фронтенде | скрытый file input с фильтром image | выбрать PNG/JPEG/WEBP |
| Показать зелёную надпись | `.photo-uploaded-status` | статус «Фото загружено» |
| Верхний левый угол блока | абсолютное позиционирование `top/left` | визуальный скриншот |
| Не показывать без изображения | условный React render | состояние до выбора файла |
| Убирать после удаления | кнопка «Удалить фото» | статус исчезает |
| Не принимать слишком большой файл | ограничение 10 МБ | видимая ошибка |
| Подтвердить автоматически | сценарий `PASS DZ8-LITE` | `npm test` |

## Схема

```text
Выбор изображения
       ↓
Проверка типа и размера
       ↓
Локальный object URL
       ↓
Предпросмотр + «Фото загружено»
       ↓
Замена или удаление
```

Изображение остаётся в текущей вкладке и не включается в экспорт проекта.

```powershell

```

Ожидаемая строка теста:

```text
PASS DZ8-LITE: статус «Фото загружено» виден только при прикреплённом изображении
```

## Что сдаётся преподавателю

1. открыть BOOK·CRAFT;
2. перейти в сценарий книги;
3. прокрутить до блока иллюстрации;
4. нажать «Добавить изображение»;
5. выбрать картинку;
6. сделать скриншот, на котором видны картинка и зелёный статус «Фото загружено»;
7. разместить скриншот на Google Диске или Яндекс Диске;
8. открыть просмотр по ссылке и отправить ссылку преподавателю.
