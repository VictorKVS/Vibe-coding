# ДЗ-8 — отдельная карточка сдачи

Раздел создан отдельно от ДЗ-6, чтобы требования, исходники, скриншоты и видео двух работ не смешивались.

## Текущий статус

| Компонент | Статус |
|---|:---:|
| Исходное задание | ⏳ требуется файл или точный текст |
| Матрица требований | ⏳ после разбора задания |
| Исходники | ⏳ после идентификации проекта |
| Автоматические проверки | ⏳ после определения критериев |
| Скриншоты | ⏳ |
| Видео сдачи | ⏳ |

После получения исходного задания здесь появятся:

1. краткий результат;
2. таблица «требование → реализация → доказательство»;
3. архитектурная схема;
4. команды запуска и тестирования;
5. перечень обязательных скриншотов;
6. открытая ссылка на видео.
