# Локальная поликлиника без платных API

Запуск: `START_LOCAL_CLINIC.cmd`. Он проверяет и при необходимости запускает локальное распознавание, установленный Ollama и сервер CRM. Повторный запуск использует уже работающий сервер. Открывается отдельный профиль поликлиники; локальная озвучка включена, её можно выключить флажком.

Компоненты: Whisper для русского распознавания, сценарный движок для надёжного сбора заявки, локальные LLM для полигона, русский голос Windows для озвучивания. В озвучивании выбираются только голоса, отмеченные браузером как локальные. Интернет не нужен для обработки после установки моделей; загрузка установочных файлов требует сети.

Проверочный разговор: хирург через два дня → в 10 утра → имя → исправленное имя → телефон частями → проверка данных → подтверждение. Все слоты и цены демонстрационные; запись в настоящую поликлинику не создаётся. Точный голос текущего голосового разговора не воспроизводится: в CRM используется русский голос Windows.

Если распознавание неверное, сохраните исходную запись. Сам сценарий не восстанавливает потерянные слова. Модель речи и её готовность видны по локальному адресу `/api/stt/health`.

На учебном компьютере установлена `ggml-large-v3-turbo-q5_0.bin` (Whisper, русский язык задан явно). Контрольная сумма SHA256 проверена. Синтетическая русская запись про приём терапевта распознана корректно; тест на CPU занял около 39 секунд. Это проверка установки, а не оценка качества на живой речи пользователя.

Если запрошенного времени нет, секретарь перечисляет доступные слоты выбранного врача на этот день. Если весь день недоступен — предлагает другие дни из его расписания. Исправление дня после выбора времени возвращает диалог к выбору слота, не заполняет имя датой и не создаёт заявку без подтверждения.
