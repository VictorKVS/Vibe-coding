# Алина — виртуальный секретарь

Файл `secretary-sprite.png` создан встроенным инструментом image_gen по запросу пользователя. Это вымышленная взрослая женщина, не изображение реального сотрудника. Два кадра отображаются CSS-переключением; исходное изображение не редактировалось. Используется в дашборде и тестовом диалоге.

Анимация: улыбка, моргание, небольшое движение головы при речи. Голос — доступный русский голос браузера через SpeechSynthesis; конкретный тембр зависит от системы. Это не видеогенерация и не точный lip-sync.

## Финальный промпт

Use case: stylized-concept. Asset type: portrait sprite sheet for an animated virtual receptionist in a polished CRM web application. Create a single landscape image with exactly TWO equal square panels side by side, no gap, no borders, no text. Both panels depict exactly the same fictional adult woman age 30, attractive warm professional virtual assistant, shoulder-length chestnut hair, expressive brown eyes, ivory blouse under elegant muted lilac blazer, small discreet earpiece, shoulders and head centered and completely inside each panel. Premium 3D game character portrait, realistic but softly stylized, polished friendly appearance, soft studio lighting, solid pale lavender background. Left panel: eyes open looking directly at viewer, gentle closed-lip smile. Right panel: exact same framing, pose, identity and lighting, eyes softly closed in a blink, slightly open mouth as if saying a short friendly word with subtle natural smile. Perfectly aligned identical head positions for CSS frame switching. Crop mid chest, keep generous margin around hair and shoulders. Tasteful business attire. No hands, no props, no captions, no watermark. Aspect ratio 2:1, ideally 1536 by 768.
