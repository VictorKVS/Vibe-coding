# DZ 5 — Integrations: files, Sheets, external APIs

Учебный проект курса Vibe Coding.

## Тема
Интеграции Telegram-бота с файлами, Google Sheets и внешними API.

## Основной проект
AI-секретарь встреч в Telegram.

### Возможности
- принимает аудио и видео;
- поддерживает обработку ссылок на большие файлы;
- извлекает аудио из видео;
- выполняет транскрибацию;
- сохраняет транскрипт в `transcripts/`;
- после успешного получения и сохранения текста отправляет отдельное сообщение: **«Транскрибация завершена успешно.»**;
- формирует саммари, задачи и ответственных;
- записывает результаты в Google Sheets;
- создаёт PDF-протокол;
- позволяет задавать вопросы по последней обработанной записи.

## Структура
```text
DZ_5_Integrations_files,_Sheets,_external_APIs/
├── README.md
├── notebooks/
├── assets/
│   └── screens/
├── docs/
├── demo/
└── transcripts/   # runtime, не хранится с пользовательскими данными
```

## Telegram demo flow
`/start → файл/видео → транскрибация → подтверждение → AI-анализ → Google Sheets → PDF-протокол → вопросы по встрече`

## Безопасность
API-ключи и токены не хранятся в репозитории. Для Google Colab используются Secrets.
