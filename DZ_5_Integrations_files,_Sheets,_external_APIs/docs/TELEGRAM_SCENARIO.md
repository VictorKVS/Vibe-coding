# Telegram-сценарий AI-секретаря

## Цель демо
Показать полный цикл интеграций темы 5: Telegram-файл → транскрибация через внешний API → сохранение текста → отдельное подтверждение успешной транскрибации → AI-анализ → Google Sheets → PDF-протокол → вопросы по записи.

## Экран 1 — START
Файл: `assets/screens/SCR-001_secretary_start.jpg`

Сообщение:
**AI СЕКРЕТАРЬ**

Превращаю записи встреч в структурированные протоколы.

Пришлите аудио, видео или ссылку на запись. Я выполню транскрибацию, выделю решения и задачи и подготовлю протокол.

## Экран 2 — FILE RECEIVED
Файл: `assets/screens/SCR-002_file_received.jpg`

После получения файла бот отправляет:
`Файл получил ✅ Сейчас обработаю.`

## Экран 3 — TRANSCRIPTION
Файл: `assets/screens/SCR-003_transcription.jpg`

Сообщение:
`🎙 Расшифровываю запись…`

После успешного получения текста и сохранения `.txt` бот ОБЯЗАТЕЛЬНО отправляет отдельным сообщением ровно один раз:

**Транскрибация завершена успешно.**

## Экран 4 — ANALYSIS
Файл: `assets/screens/SCR-004_analysis.jpg`

Сообщение:
`🧠 AI анализирует встречу… Выделяю основные темы, задачи, ответственных и дату следующей встречи.`

В фоне выполняются:
- извлечение саммари;
- извлечение задач;
- определение ответственных;
- определение следующей встречи;
- запись строк в Google Sheets.

## Экран 5 — PROTOCOL READY
Файл: `assets/screens/SCR-005_protocol_ready.jpg`

Сообщение:
`✅ Обработка завершена. Данные встречи сохранены. Протокол подготовлен.`

Под сообщением настоящая Telegram inline-кнопка:
`📄 Скачать протокол PDF`

## Экран 6 — ASK AI
Файл: `assets/screens/SCR-006_ask_ai.jpg`

Сообщение:
`💬 Теперь можете задавать вопросы по этой встрече.`

Правило ответа: только по сохранённому транскрипту. Если ответа нет: `В записи это не обсуждалось.`

## Визуальный стиль
Корпоративный AI-assistant: графитовый/тёмно-синий фон, бирюзовые технологические акценты, белая типографика, современная переговорная, микрофон/аудиоволна/документы/AI. Никаких нарисованных Telegram-кнопок внутри изображений — кнопки создаются Bot API.
