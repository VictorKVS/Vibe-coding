# Telegram UI screens

Папка для визуалов AI-секретаря.

Планируемые файлы:

- `SCR-001_secretary_start.jpg` — стартовый экран AI-секретаря;
- `SCR-002_file_received.jpg` — файл принят;
- `SCR-003_transcription.jpg` — идёт транскрибация;
- `SCR-004_analysis.jpg` — AI анализирует встречу;
- `SCR-005_protocol_ready.jpg` — PDF-протокол готов;
- `SCR-006_ask_ai.jpg` — вопросы по встрече.

Изображения не должны содержать нарисованных Telegram-кнопок. Кнопки создаются средствами Telegram Bot API.
